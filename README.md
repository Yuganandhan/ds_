# Web3 Trading Team Data Science Assignment

## Project Overview
This project analyzes the relationship between trader behavior and Bitcoin market sentiment using two key datasets:  
- **Historical Trader Data from Hyperliquid:** Contains detailed trade-level data including execution price, size, side, leverage, and profitability metrics.  
- **Bitcoin Fear & Greed Index:** A daily sentiment index categorizing the Bitcoin market sentiment as Fear, Greed, Extreme Fear, or Extreme Greed.

The goal is to explore how trading behavior (profitability, risk, volume, leverage) varies with market sentiment, identifying patterns and insights that could inform smarter trading strategies.

## How to Run
1. Open `notebook_1.ipynb` in Google Colab.  
2. Mount your Google Drive, or upload the CSV files stored in `csv_files/` for data access.  
3. Run each code cell sequentially—from data loading, cleaning, merging, to visualization and statistics.  
4. Review generated plots saved into the `outputs/` folder and data saved into `csv_files/`.  
5. For extended analyses, open `notebook_2.ipynb`.

## Key Findings
- Trading behaviors differ significantly between Fear and Greed market days.  
- Profitability (closed PnL) tends to be higher during Greed phases, with different leverage profiles observed.  
- Trade volumes and risk-taking behavior respond to changes in market sentiment.  
- These insights can guide sentiment-aware trading strategies for improved decision-making.
